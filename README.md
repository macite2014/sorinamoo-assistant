# sorinamoo assistant (자체 자동제어 앱)

기존에 쓰던 Home Assistant를 백엔드(자동제어 엔진)로 그대로 두고, 그 위에 우리 브랜드로 만든 전용 제어 화면입니다. 조명·스위치·음향·센서·장면(큐)을 한 화면에서 켜고 끄고, 모바일 홈 화면에 앱처럼 설치할 수 있습니다.

## 실행 주소 (GitHub Pages)

**https://macite2014.github.io/sorinamoo-assistant/**

이 주소로 바로 접속해서 사용할 수 있습니다. 모바일에서 열고 "홈 화면에 추가"하면 앱처럼 아이콘이 생깁니다.

## ⚠️ 중요: HTTPS ↔ HTTP 주의사항

위 GitHub Pages 주소는 `https://`로 제공됩니다. 그런데 댁/현장의 Home Assistant 서버가 `http://192.168.x.x:8123`처럼 암호화되지 않은 주소라면, 브라우저가 보안 정책(Mixed Content)으로 인해 연결을 차단할 수 있습니다.

해결 방법 (택 1):
1. **Home Assistant에 HTTPS 적용**: Nabu Casa 클라우드 연결, 또는 Cloudflare Tunnel / Nginx Proxy Manager 등으로 `https://` 주소를 만들어 그 주소로 연결
2. **앱을 로컬에서 직접 실행**: GitHub Pages 대신 `index.html`을 PC에서 직접 열거나, 같은 네트워크의 서버(라즈베리파이 등)에서 `http://`로 띄워서 사용 (이 경우 Mixed Content 제한이 없음)

데모 모드는 이 문제와 무관하게 항상 정상 동작합니다.

## 구성 파일

- `index.html` — 앱 본체 (이 파일 하나로 동작)
- `manifest.json`, `service-worker.js`, `icon.svg` — 홈 화면에 앱처럼 설치(PWA)하기 위한 파일

## 1. 먼저 데모로 체험하기

`index.html`을 더블클릭해서 브라우저로 열고, "서버 없이 데모로 먼저 체험하기"를 누르면 가상 기기로 화면 구성을 바로 확인할 수 있습니다. 실제 서버 연결 전에 레이아웃과 동작을 점검하는 용도입니다.

## 2. 실제 Home Assistant에 연결하기

### 토큰 발급
1. Home Assistant 웹 화면 접속 → 좌측 하단 프로필(이름) 클릭
2. "보안" 탭 → 맨 아래 "토큰 만들기(Long-Lived Access Token)"
3. 이름을 적고 생성 → 표시되는 토큰 문자열을 복사 (다시 볼 수 없으니 안전한 곳에 보관)

### 앱에 연결
1. 연결 화면에서 브랜드 이름, 서버 주소(예: `http://192.168.0.10:8123`), 토큰을 입력
2. "연결하기" 클릭

### 만약 연결 실패가 뜬다면 (CORS)
Home Assistant는 기본적으로 외부 출처(다른 주소)에서의 API 요청을 막아둘 수 있습니다. `configuration.yaml`에 아래처럼 허용 출처를 추가해야 할 수 있습니다.

```yaml
http:
  cors_allowed_origins:
    - "https://내가-이-앱을-올린-주소"
```

앱을 로컬 파일(`file://`)로 그냥 열어서 쓰는 경우에는 보통 CORS 문제가 없는 경우가 많지만, 별도 웹서버에 올려서 쓸 경우에는 위 설정이 필요할 수 있습니다.

## 3. 호스팅 방법 (택 1)

- **가장 간단**: 이 폴더를 그대로 PC나 태블릿에 두고 `index.html`을 더블클릭해서 사용
- **사내망에서 누구나 접속**: 이 폴더를 Home Assistant가 설치된 서버, 시놀로지 NAS, 라즈베리파이 등에 두고 아주 간단한 정적 웹서버로 띄우기
  ```bash
  cd 이폴더경로
  python3 -m http.server 8090
  ```
  이후 같은 네트워크의 다른 기기에서 `http://서버IP:8090` 으로 접속
- **모바일 홈 화면에 앱처럼 설치**: 위 방식으로 띄운 주소를 모바일 브라우저(크롬/사파리)로 열고 "홈 화면에 추가" 선택 → 아이콘이 생기고 앱처럼 전체화면으로 실행됨

## 4. 화면 구성

- **조명**: 켜기/끄기 토글, 밝기 조절 슬라이더
- **스위치/설치물**: 켜기/끄기 토글 (분수, 사인물, 전원 등)
- **음향**: 재생/일시정지, 볼륨 슬라이더
- **센서/환경**: 온도·소음·동작감지 등 읽기 전용 표시
- **장면/자동화**: 미리 등록한 큐(오프닝, 피날레, 비상조명 전환 등) 실행 버튼

5초마다 자동으로 상태를 갱신합니다(설정에서 주기 변경 가능). 우측 상단 ⚙ 에서 브랜드 이름, 서버 주소, 토큰, 새로고침 주기를 언제든 변경할 수 있습니다.

## 5. 현재 버전의 한계 / 다음 단계 제안

- 지금은 HA의 REST API(폴링 방식)로 동작합니다. 기기가 많아지면(50개 이상) WebSocket API로 전환해 실시간성을 높일 수 있습니다.
- 엔티티는 도메인(light/switch/sensor 등) 기준으로 묶입니다. 구역(무대/입구/광장 등)별로 묶고 싶다면 Home Assistant에서 "지역(Area)"을 지정해두면 다음 버전에서 지역별 그룹핑으로 확장할 수 있습니다.
- 운영자별 권한 분리(예: 음향 담당은 음향만 보이게)가 필요하면 알려주시면 추가하겠습니다.
